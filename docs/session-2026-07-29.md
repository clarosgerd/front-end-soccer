### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/match/{match}/ai-prediction` | Single match prediction |
| GET | `/tournament/{tournament}/ai-predictions` | All upcoming predictions for a tournament |
| GET | `/ai-predictions/accuracy` | Model accuracy stats |

### Artisan Command

```
php artisan ai:predict [--tournament=X] [--match=X] [--evaluate]
```

Generates predictions for upcoming matches without existing AI predictions (up to
200 per run). Evaluates finished matches that have predictions but no
`was_correct` flag. Outputs accuracy table on completion.
